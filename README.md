## Publicar gratuitamente com GitHub Pages
1. Entre no GitHub e crie um repositório público, por exemplo `educacao-dados-santo-andre`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`; clique em **Save**.
6. Aguarde alguns minutos. O GitHub exibirá o endereço público na seção Pages, geralmente:
   `https://SEU-USUARIO.github.io/educacao-dados-santo-andre/`

Os gráficos usam Chart.js por CDN e precisam de conexão à internet para serem renderizados.
Os números foram transcritos dos documentos-base fornecidos; consulte a aba “Fontes e notas metodológicas”.
